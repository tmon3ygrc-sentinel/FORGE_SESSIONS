# FORGE_SESSIONS

Personal music production repo — lyrics, tabs, Suno AI prompt library, and
playlists for original material. Standalone project, no connection to any
other repo/silo on this machine.

## Structure

- `lyrics/` — song lyrics, drafts and finished
- `songs/` — finished tracks / project files / exports
- `tabs/` — guitar and bass tabs
- `prompts/` — Suno AI prompt library (style/genre/structure prompts used to generate tracks)
- `playlists/` — curated playlists, running order notes, setlists
- `archive/` — retired/superseded material, kept for reference rather than deleted

See `SESSIONS.md` for a running log of work sessions on this project.
