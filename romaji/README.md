# Romaji Pronunciation & Cultural Guide

## Pronunciation key

を is written “wo” in the romaji but normally pronounced “o” (without a strong w). In the pronunciation guides below, read “wo” as “o.” Macron vowels (ō / ū) are held longer; “show” and “yoo” indicate these long vowels without an added English glide. Other adjacent vowels should each be sounded.
